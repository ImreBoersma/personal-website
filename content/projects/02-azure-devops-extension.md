Tijdens mijn afstudeerstage bij Infocaster bouwde ik een Azure DevOps-extensie in Vue.js 3 met een .NET-API. Daarmee bracht ik data uit verschillende monitoringtools samen op één plek, zodat ontwikkelaars de status van hun projecten konden zien zonder steeds tussen systemen te hoeven wisselen.
